2. SHORT MARKETPLACE INTRODUCTION
============================================================

BoltIQ Gold EA is an automated MetaTrader 5 Expert Advisor designed
primarily for XAUUSD (Gold) trading.

The EA combines a rule-based trend-following strategy with an optional
ONNX machine-learning filter. The core strategy uses EMA trend
detection, RSI momentum confirmation, ADX trend-strength filtering and
ATR-based volatility management.

The ML filter is optional. Traders can run the EA using the rule-based
strategy alone or enable the supplied ONNX model as an additional
trade-selection layer.

BoltIQ Gold EA also includes account-level risk controls such as daily
loss protection, maximum drawdown monitoring, session controls,
economic-news filtering, configurable risk sizing and position limits.

5. HOW THE TRADING STRATEGY WORKS
============================================================

BoltIQ Gold EA does not rely on a single indicator for its core entry
logic.

The rule-based strategy combines trend direction, momentum and trend
strength before considering an entry.

5.1 Trend Direction

The EA uses EMA(20) and EMA(50) to identify potential bullish or bearish
trend direction.

5.2 Momentum Confirmation

RSI(14) is used as a momentum filter.

Long setup: RSI(14) > 55

Short setup: RSI(14) < 45

5.3 Trend Strength Confirmation

ADX(14) must be above 25 before an entry is considered.

5.4 Volatility Management

ATR(14) is used to adapt stop-loss distance to current market volatility.

5.5 Closed-Bar Signals

The supplied product description specifies that the strategy operates
using closed-bar information.

8. OPTIONAL ONNX MACHINE-LEARNING FILTER
============================================================

The ML component is an optional additional filtering layer.

8.1 How It Works

The EA can:

1. Detect a setup using the core rule-based strategy.
2. Pass the setup features to the supplied ONNX model.
3. Receive the model's output probability.
4. Compare the result with the configured ML threshold.
5. Allow or block the setup according to the configuration.

8.2 Configuration

UseMLFilter = false by default.

MLModelPath = "BoltIQ_Gold_Filter.onnx"

MLThreshold can be configured within the supported range.

The ML filter can therefore be used as an optional trade-selection
mechanism rather than being required for the core strategy to operate.

8.3 ML Model Information From the Current Product Description

The existing product information states:

- Model format: ONNX.
- Architecture: Feed-forward neural network.
- Target: Binary classification of trading setups.
- Training data stated in the existing listing: 2020–2023 XAUUSD M15
  data.
- The existing listing also states that the model was walk-forward
  validated.

BoltIQ Gold EA separates trading logic from account-level risk controls.

high-impact events.

Position limits help prevent excessive simultaneous exposure and
overtrading.

different trade count, win rate or profit factor in one historical test
does not establish that the ML filter will improve live performance.

The ML model may also behave differently as market conditions change.

- The rule-based configuration.
- The ML-enabled configuration.
- The broker's actual execution conditions.
- The selected ML threshold.
- Out-of-sample or forward-test behavior.
- Risk and drawdown under the intended account rules.

No verified live or forward-test track record is claimed in the supplied
product information.
